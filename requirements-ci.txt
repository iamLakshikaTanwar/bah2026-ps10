# This is the *trimmed* dependency set CI installs to run the synthetic demo +
# the core test suite on a plain ubuntu-latest runner — NOT the full

#

# without them and the corresponding tests `pytest.importorskip(...)` / skip
# gracefully, so a green CI here proves the runnable core (config + interfaces +
# synthetic data + tiny nets + self-contained metrics + the O(1) color-LUT).
#
# NOTE: torch + torchvision are installed SEPARATELY in the CI workflow from the
# CPU wheel index (https://download.pytorch.org/whl/cpu) so the runner never pulls
# multi-GB CUDA wheels. They are intentionally omitted from this file.
# ===========================================================================
